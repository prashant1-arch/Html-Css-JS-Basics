# ✨ Text Floating Animation

## 📖 About The Project

**Text Floating Animation** is a simple web development project created using **HTML and CSS**.

The project displays the text **"Prashant Savita"** in the center of the webpage with a continuous floating/rotating animation. The animation is created using CSS `@keyframes`.

This project demonstrates how CSS animations, Google Fonts, text-shadow, and rotation can be used to create an attractive text effect.

## ⚙️ How It Works

The project uses an `<h1>` element to display the name:

```html
<h1>
  Prashant <br />
  Savita
</h1>
```

The text animation is applied using:

```css
animation: textfloating 1s linear infinite alternate;
```

The `@keyframes` rule changes the rotation of the text:

```css
@keyframes textfloating {
  0% {
    rotate: 15deg;
  }

  50% {
    rotate: 0deg;
  }

  100% {
    rotate: -15deg;
  }
}
```

The `alternate` property makes the animation move back and forth continuously.
